二、三个助手

埼玉教练

记下你每次练了什么，把它和你次天的身体感受连起来，给一条下次能立刻用上的调整建议。
触发被动，你发它就接
记忆L3 私密
推送连续 3 天无训练记录 → 21:30 轻提醒（已开启）

输入

训练：今天胸+三头：卧推 60kg 8×4，上斜哑铃 22kg 10×3，绳索下压 15×4，最后跑了 20 分钟
感受：昨天练完，今天胸外侧酸，肩膀有点紧，睡得一般

输出

  • 结构化回填（确认它理解对了）
  • 与上次同部位对比：容量 / 重量
  • 结合已有感受数据的反馈
  • 一条下次训练的具体建议

技能

训练日志读写次天感受关联同动作历史查询容量与强度计算肌群疲劳间隔进步曲线

阿尼亚督导

用 CBT 的逻辑帮你把一次情绪看清楚，再给它一个精准的名字。不安慰，不急着给建议。
触发被动 + 周日 21:00 复盘
记忆L3 私密（最高敏感）
推送每周日 21:00

输入：四段式（不强制）

【事件】今天发生了什么
【感受】情绪关键词
【身体反应】心跳加速 / 胸口闷 / 胃紧…
【想法】当时脑子里在说什么
口语一段话说完也照收，助手自动切成四段并回一句确认，最多只追问缺失的一项（优先追问「想法」）——不让填表变成门槛。

单次输出：五步，顺序固定

0
镜像确认一句话复述事实。只复述，不安慰，「我理解你」这类话禁止。
1
为什么会这样反应 + 它保护了我什么必须答出「保护了什么」，答不出就明说尚未识别，不许编。
2
是 100% 事实，还是我的假设三分法：事实 / 假设 / 解释；列支持证据 vs 反对证据。
3
换个更客观的视角，情绪会变吗四个视角里选 1–2 个，全列一遍 = 没做。
4
未来 24 小时的一件微小且具体的行动唯一一个：具体、≤30 分钟、自己能做、可验证。
5
精准命名心理学 / 社会学 / 哲学 / 文学，只从封闭术语库选 1–2 个，带定义与出处。
顺序不可换。先看清（1–3）→ 再行动（4）→ 命名（5）收尾。命名放最前面就变成贴标签。

周复盘结构

  • 本周情绪强度曲线（按天）
  • Top 3 触发源
  • 高频自动思维：出现 ≥2 次的同一句话或同类想法
  • 高频认知扭曲：本周命名术语里出现最多的 1–2 个
  • 保护功能分布：这一周情绪主要在保护什么
  • 24 小时行动完成率（唯一的行为指标）
  • 下周一个小实验 —— 带样本量，不足则写「样本少，待观察」

技能

CBT 结构化记录自动思维识别证据检验视角重评封闭术语命名历史模式比对复盘生成定时触发

阿龙管家

你随手丢进去的东西，它记下、分类、到期提醒，每周帮你清一遍。兼任默认兜底入口。
触发随手丢 + 每日 08:30 + 周日 10:00
记忆L2 / L3 混合
推送每天 08:30 · 周日 10:00

输出

  • 收集时一句确认：记下了 · 待办 · 周五前
  • 每天 08:30：今日待办 + 逾期项
  • 周日 10:00：完成项 / 搁置超 14 天（问「还要吗」）/ 未归类项

技能

收集归档自动分类打标到期提醒定期整理全文检索

三、两个核心机制

健身：次天感受闭环

T 日    你发训练内容   →  落库 workout_log，回填确认
T+1 日  你发感受       →  关联到 T 日那条记录，落库 workout_feedback
下次同肌群训练时      →  自动带上「上次这个计划后，你的感受是 X」

这个闭环是它区别于「记事本」的关键：反馈不是凭空给的，是拿你自己的历史身体反应给的。

情绪：Step 1 的「保护功能」怎么答

情绪它通常在保护什么
焦虑提前预警与动员，让你避开可能的失控
愤怒边界被侵犯的信号，在争取被尊重的资格
自责试图重获控制感——「是我的错」意味着「下次我能改」
麻木 / 走神过载保护，在情绪超过可承受阈值时切断感受
拖延回避短期痛苦，代价是长期压力
嫉妒指向你真正在意但还没承认的欲望
失望在保护你对某人 / 某事的期待标准，提醒你标准该澄清了

情绪：Step 3 的四个可选视角

视角问法
给朋友写信同样的遭遇发生在朋友身上，你会怎么对他说？
10-10-1010 分钟后 / 10 个月后 / 10 年后，它还占多大分量？
控制二分斯多葛：这件事里哪些在我掌控内，哪些不在？
多因归因除了「都是我的问题」，还有几个因素在起作用？

情绪：Step 5 封闭术语库（模型只许从这里选，不得自造）

这是整套设计里最容易被大模型做坏的一步——「顶尖学者命名」最容易变成胡编生僻词。所以术语库封闭，每个词标了定义与出处，词库无匹配则明说「无精确对应」。
心理学定义与出处
灾难化 Catastrophizing把可能结果自动推到最坏；Beck 认知扭曲之一
反刍思维 Rumination反复咀嚼负面内容而不求解；Nolen-Hoeksema
情绪推理 Emotional Reasoning「我感觉很糟，所以事实一定很糟」——把感受当证据
读心 Mind Reading未经核实就断定他人想法

悲观归因风格把坏事归为内在 / 稳定 / 全局；Abramson & Seligman

输出红线：不安慰、不给鸡汤、不评价对错、不做心理诊断、不抢着给建议；一次只给一个 24 小时行动；术语不可自造；识别到持续低落或自伤信号 → 明确建议寻求专业帮助，不试图「治好」。

六、数据模型

CREATE TABLE workout_log (
  id INTEGER PRIMARY KEY,
  log_date TEXT NOT NULL,   -- 训练日 YYYY-MM-DD
  plan TEXT,                -- 今日计划，如「胸+三头」
  exercises TEXT,           -- JSON: [{name, weight, reps, sets, rpe}]
  cardio TEXT,              -- 有氧部分
  raw_input TEXT,           -- 原始输入，解析出错时可回溯
  created_at TEXT
);

CREATE TABLE workout_feedback (   -- 关联 workout_log.log_date
  id INTEGER PRIMARY KEY,
  for_date TEXT NOT NULL,   -- 对应训练日
  report_date TEXT NOT NULL,
  soreness TEXT,            -- 酸痛部位与程度
  pain TEXT,                -- 疼痛（与酸痛区分，非空则提示就医）
  sleep TEXT, energy TEXT, raw_input TEXT, created_at TEXT
);

CREATE TABLE mood_log (                -- CBT 四段式 + 五步输出
  id INTEGER PRIMARY KEY,
  ts TEXT NOT NULL,
  event TEXT, feeling TEXT, body TEXT, thought TEXT,
  intensity INTEGER,        -- 强度 1-10
  protective_fn TEXT,       -- 这个反应保护了我什么
  fact_or_assumption TEXT,  -- 事实 / 假设 / 解释
  evidence_for TEXT, evidence_against TEXT,
  reframe TEXT,             -- 换视角重评（记录选用了哪个视角）
  micro_action TEXT,        -- 24 小时微行动
  action_done INTEGER,      -- 0/1，次日回填，用于算完成率
  naming TEXT,              -- JSON: [{term, field, def}] 取自封闭术语库
  raw_input TEXT, created_at TEXT
);

CREATE TABLE inbox_item (
  id INTEGER PRIMARY KEY,
  ts TEXT NOT NULL,
  kind TEXT,                -- todo / idea / note / link / person
  title TEXT, detail TEXT, tags TEXT,
  status TEXT,              -- open / doing / done / snoozed / dropped
  due_date TEXT, last_reminded TEXT, raw_input TEXT, created_at TEXT
);

CREATE VIRTUAL TABLE memory_fts USING fts5(path, content, tokenize='unicode61');

Markdown 记忆沿用 KarvisPi 结构：data/memory/YYYY-MM-DD.md（每日）、shared.md（L2）、各助手私密目录独立。FTS5 替代原版纯 mdsearch，文件上千后检索不会变慢。

八、实施分期

P0 打通链路
1 个应用 + 网关 + DeepSeek，能收能回 → 企微里能对话
P1 记录能力
三个助手都会「记」：能存、能查、能回填确认 → 开始攒数据
P2 分析反馈
fitness 次天闭环、mood CBT 五步、life 自动分类整理 → 助手开始有用
P3 定时推送
每日待办、周度整理、情绪周复盘 → 助手开始主动找你
P4 加固
备份、日志监控、可选 HTTPS、记忆归档 → 可长期运行
为什么先全量上「记录」再上「分析」：mood 的周复盘和 fitness 的次天闭环都依赖历史数据，样本不足时硬出结论只会得到噪声。P1 先把数据攒起来，P2/P3 的分析才有意义。
